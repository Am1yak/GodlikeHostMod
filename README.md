# Godlike.host Mod
Adds a button to Multiplayer menu that redirects you to godlike.host site

## Versions
Builds for latest stable versions for Fabric 1.20.1, Forge 1.20.1 and Forge 1.12.2

## Installation
1. In root folder and folder for Forge 1.12.2(forge-1122) you need to change gradle.properties.example to gradle.properties and provide working java 17 and java 8 paths to work
2. run ./gradlew clean build in root
3. All three versions wil be in /build/libs
